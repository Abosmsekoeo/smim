# صمّم

تطبيق عربي لتحرير الصور والتصميم على الجوال (Android وiOS) مبني بـ Expo وReact Native وSkia.
كل المعالجة محلية على الجهاز: لا حساب، ولا رفع للصور.

الهوية: شعار «صمّم» أبيض على أسود، وواجهة سوداء بعناصر بيضاء، ونصوص عربية بصيغة المذكر.

## الأدوات

| الأداة | ما تقدمه |
|---|---|
| قص | مقابض سحب حرة، نسب جاهزة (1:1، 4:5، 3:4، 9:16، 16:9، 4:3، 3:2، أصلي)، تدوير 90° يمينًا ويسارًا، قلب أفقي وعمودي، تسوية الميل (±45°) |
| ضبط | 15 معاملًا: التعريض، السطوع، التباين، الإضاءات العالية، الظلال، البهتان، التشبّع، الحيوية، الدفء، الصبغة، درجة اللون، الحدّة، التمويه، تعتيم الحواف، الحبيبات |
| فلاتر | 15 فلترًا بمعاينات مصغرة وشدة قابلة للتحكم |
| نص | عربي ولاتيني، 9 خطوط، لون، ظل، حدود، خلفية، محاذاة، حجم، شفافية، تدوير |
| أشكال | 22 شكلًا متجهيًا بتعبئة وحدود وحجم وشفافية وتدوير |
| رسم | فرشاة بلون وحجم وشفافية |
| إطار | إطار بسماكة ولون |
| عام | تراجع وإعادة (80 خطوة)، «قبل وبعد» بالضغط المطول، تحريك العناصر بإصبع وتكبيرها وتدويرها بإصبعين، حذف وتكرار وترتيب الطبقات، لوحة فارغة بمقاسات جاهزة |
| تصدير | JPG أو PNG، جودة، حجم (أصلي حتى 4096 / متوسط 2048 / صغير 1080)، حفظ في المعرض أو مشاركة |

## التشغيل

```bash
npm install
npx expo install --fix     # يضبط إصدارات حزم Expo بما يناسب إصدار Expo المثبّت
npm run check:fonts        # يتأكد أن ملفات الخطوط موجودة
npm test                   # اختبارات المنطق (بلا حاجة لجهاز)
npm run typecheck
npx expo start             # ثم افتح التطبيق في Expo Go
```

Skia وملفات الخطوط تعمل داخل Expo Go. حفظ الصور في المعرض قد يحتاج نسخة APK حقيقية على بعض إصدارات Android.

## بناء APK

**الخيار 1: GitHub Actions (بدون حساب Expo).** ارفع المشروع إلى GitHub، ثم من تبويب Actions شغّل «Build Android APK». يظهر ملف الـ APK ضمن Artifacts عند انتهاء البناء. الملف موقّع بمفتاح تجريبي، ويصلح للتجربة والتثبيت المباشر، لا للنشر في المتجر.

**الخيار 2: EAS.**
```bash
npm i -g eas-cli
eas login
eas build -p android --profile preview
```

**الخيار 3: محليًا** (يتطلب Android Studio وJDK 17):
```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
```

قبل النشر في المتجر غيّر `com.samim.designer` في `app.json` إلى معرّفك الخاص.

## هيكل الكود

```
src/lib/        منطق صرف بلا React ولا Skia (قابل للاختبار): الحالة، التاريخ، الهندسة، اللمس، الضبط، الفلاتر، الأشكال، الشيدر
src/skia/       رسم Skia: المشهد Scene (يُستخدم للمعاينة والتصدير معًا)، النص، الخطوط، الاستيراد والتصدير
src/components/ لوحة المحرر، الألواح، النوافذ
src/screens/    الشاشة الرئيسية والمحرر
tests/          اختبارات المنطق
```

مبدأ التصميم: مشهد واحد `Scene` يرسم كل شيء بإحداثيات الصورة، فالمعاينة والتصدير يخرجان من الكود نفسه، وما تراه هو ما يُحفظ. تُعالَج الألوان بشيدر SkSL على المعالج الرسومي، وإن فشل تجميعه على جهاز ما يعود التطبيق تلقائيًا إلى مصفوفة ألوان أبسط.

## ما اختُبر وما لم يُختبر

اختُبر:
- منطق الحالة بـ 35 اختبارًا (`npm test`): التراجع والإعادة، تدوير الصورة وقلبها وانتقال العناصر معها، القص ونسبه وحدوده، حركات اللمس (سحب وقرصة وتدوير)، لمس العناصر، المنزلقات، معاملات الضبط والفلاتر، سلامة الأشكال، وتطابق متغيرات الشيدر مع تصريحاته.
- رسم الأشكال الـ 22 في متصفح (تظهر كلها صحيحة).
- معادلات الشيدر نفسها نُقلت إلى WebGL وجُرّبت على صورة اختبار: التعريض والتباين والتشبّع والدفء والصبغة ودرجة اللون والبهتان والحدّة وكل الفلاتر تعطي النتيجة المتوقعة.

لم يُختبر على جهاز (لم يتوفر في بيئة التطوير تثبيت الحزم):
- تشغيل التطبيق نفسه، ورسم Skia والنص العربي (Paragraph) والتصدير بـ `drawAsImage`، وحفظ الملف في المعرض.
- إحساس اللمس (القرصة والسحب) على شاشة حقيقية.
- مسارات ملفات الخطوط داخل `node_modules`: يتحقق منها `npm run check:fonts`.
- إصدارات الحزم في `package.json` مبنية على Expo SDK 54؛ إن اشتكى `npm install` من إصدار فشغّل `npx expo install --fix`.

عند أول تشغيل جرّب بالترتيب: اختيار صورة، سحب منزلق، فلتر، قص، إضافة نص عربي، شكل، رسم، تصدير وحفظ.

## حدود معروفة
- لا تكبير ولا تحريك للوحة المعاينة نفسها.
- التمويه عام على الصورة كلها (لا فرشاة تمويه موضعية).
- لا ممحاة للرسم؛ استخدم التراجع أو «مسح الرسم».
- المسافة بين الأحرف تُعطَّل للنص العربي حتى لا تنفصل الحروف.
